se# Venue Booking System

A web-based venue booking and management application developed using Python and Streamlit.

## Live Application

**[Click here to access the Venue Booking System](https://venuebooking-ckftcrujbcqeuyefuskyra.streamlit.app/)**

## Features
- Interactive venue availability calendar
- Customer booking requests
- Additional services and options
- Booking tracking
- Payment reference management
- Staff login and booking approval
- Walk-in customer registration
- Booking cancellation

## Technologies
- Python
- Streamlit
- SQLite
- GitHub

## Deployment
Streamlit Community Cloud
